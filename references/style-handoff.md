# 应用团队文风

文书的内容由本案材料、程序、确认的提纲和请求决定。风格规则用于处理标题、顺序、语气、说明长度和段落衔接。

## 选择画像

优先使用用户在本次任务中明确指定的路径、版本或名称。读取相应 Skill 的入口及适用文体。律师文风工坊生成的独立 Skill 可直接使用，其他团队画像也可用。用户未指定画像时，根据当前文书目的用通用中文法律文书表达。需要按某位律师或某个团队写而找不到画像时，先说明这一点，用已给出的要求继续可做部分。

## 应用与终稿核对

给风格模块的输入限于当前案已授权的材料、被保留的争点、当事人程序角色、请求和引用位置。原话、有效否定、程度和备位条件随论点一同提供。

改写完逐项核对标题与正文学理对应、当事人、裁判审级、证据证明范围、引用和请求。段末要交代该段结论与程序结果的联系。若风格建议增加或删除独立观点、改变归因或证据效力，返回尚待用户确认的步骤。

用户交回修改稿时，可将文字改动和案件实质变更分别交给用户指定的团队风格生成器学习。由用户控制画像的更新范围。共同案件背景不能作为后案的事实来源。
